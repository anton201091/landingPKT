# ПКТ — Производственный контур театра

Публичная презентационная страница проекта **ПКТ** — цифровой системы управления созданием, выпуском и эксплуатацией спектакля.

Сайт: https://anton201091.github.io/landingPKT/

## Что находится в этом репозитории

Только публичная витрина проекта: описание проблемы, принцип работы, ключевые модули, роли и концепция эксплуатации.

Рабочий продукт, исходный код основной системы, внутренняя архитектура, модель данных, API, миграции и алгоритмы здесь **не публикуются**.

## Назначение

Страница подготовлена для:
- знакомства театров с продуктом;
- презентации потенциальным пилотным площадкам;
- заявок на гранты и программы поддержки;
- профессиональной экспертизы проекта.
